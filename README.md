# People Analytics: Workforce & Development Insights

This Power BI project explores workforce and development-related HR data to identify patterns and insights across different employee groups, roles, and organizational indicators.

The dashboard focuses on workforce structure, learning and development indicators, engagement and performance metrics, and potential workforce risk factors such as attrition and overtime.

The project is based on the IBM HR Analytics Employee Attrition & Performance dataset from Kaggle: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset
